# Plan: 重新分析按钮

## 目标
在 home-dashboard 的报告操作栏中新增一个"重新分析"按钮，点击后对当前选中的股票发起带 `force_refresh=true` 的分析请求，忽略缓存重新获取数据并生成报告。

## 改动面分析

### 1. `stockPoolStore.ts` - 扩展 `submitAnalysis` 支持 `forceRefresh`
**文件**: `apps/dsa-web/src/stores/stockPoolStore.ts`

- **SubmitAnalysisOptions 类型扩展**（第 20-26 行）：新增 `forceRefresh?: boolean` 字段
- **submitAnalysis 方法**（第 303-376 行）：
  - 从 options 中提取 `forceRefresh`
  - 在调用 `analysisApi.analyzeAsync()` 时传入 `forceRefresh` 参数（第 341-348 行）

### 2. `HomePage.tsx` - 新增"重新分析"按钮
**文件**: `apps/dsa-web/src/pages/HomePage.tsx`

- 在报告操作栏（第 276-298 行）中，在"追问 AI"和"完整报告"按钮之前新增"重新分析"按钮
- 新增 `handleReanalyze` 回调函数：
  - 从 `selectedReport.meta` 获取 `stockCode` 和 `stockName`
  - 调用 `submitAnalysis()` 并传入 `forceRefresh: true`
  - 使用 `selectedReport.meta.stockCode` 作为 `stockCode`
  - 设置 `selectionSource: 'manual'`（因为是用户主动触发）
- 按钮样式：使用 `variant="home-action-ai"` 和 `size="sm"`，与现有按钮一致
- 按钮图标：使用刷新/循环图标（refresh/reload SVG）
- 按钮文案：中文"重新分析"
- 禁用条件：`isAnalyzing` 为 true 时禁用

### 3. `reportLanguage.ts` - 国际化文案
**文件**: `apps/dsa-web/src/utils/reportLanguage.ts`

- 在 `REPORT_TEXT.zh` 和 `REPORT_TEXT.en` 中新增 `reanalyze` 字段：
  - zh: `'重新分析'`
  - en: `'Re-analyze'`

### handleReanalyze 回调
```tsx
const handleReanalyze = useCallback(() => {
  if (!selectedReport) return;
  void submitAnalysis({
    stockCode: selectedReport.meta.stockCode,
    stockName: selectedReport.meta.stockName,
    originalQuery: selectedReport.meta.stockCode,
    selectionSource: 'manual',
    forceRefresh: true,
  });
}, [selectedReport, submitAnalysis]);
```

## 风险点

1. **重复任务处理**：如果同一股票正在分析中，后端会返回 409，前端已有 `DuplicateTaskError` 处理逻辑，会显示"正在分析中"的提示，行为正确。
2. **force_refresh 后端支持**：API schema 中已有 `force_refresh` 字段（`api/v1/schemas/analysis.py`），pipeline 中也有缓存跳过逻辑，无需后端改动。
3. **按钮禁用状态**：仅在 `isAnalyzing` 时禁用，不依赖 `selectedReport` 是否存在（因为按钮只在有报告时渲染）。
